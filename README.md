# 🎯 早押しクイズ道場

本格的な早押しクイズゲームです。4択で回答できます！

## 🎮 遊び方

1. ジャンルカードをクリック → **即スタート！**
2. 問題文が流れるように表示される
3. わかったら「⚡ 回答する！」ボタンを押す
4. 4択から正解を選ぶ
5. 正誤表示 → 次の問題へ

## ✨ 特徴

- **1000問以上**収録（10ジャンル）
- **4択回答**形式
- **制限時間120秒**のタイムアタック
- 正解で +10点 +5秒、不正解で -5秒
- 残り時間がそのままボーナス点に加算
- **ローカルスコアランキング**（上位20件保存）
- 間違えた問題を復習できる

## 🚀 プレイ方法

### GitHub Pagesでオンラインプレイ
1. このリポジトリをフォーク または クローン
2. GitHubの Settings → Pages → Source を `main` ブランチの `/root` に設定
3. 公開URLでアクセス

### ローカルでプレイ
```
index.html をブラウザで開くだけ！
```

## 📝 注意事項

- スコアはブラウザのLocalStorageに保存（端末ごとに保存）
